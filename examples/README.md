# Examples

These are real RecompLauncher manifests from two working GameCube recomps.
No game data or assets are included.

- [spongebob](spongebob/) - `GSQE78`, ISO-only, 13 settings, JIT/static
  `--core` setting, Redump dump, headless prepare.
- [rocketpower](rocketpower/) - `GBQE78`, `iso_or_folder`, `check.ids` +
  `check.file`, `MODERNGEKKO_STATICRECOMP=0` env, JIT playable release.

Use them as references, not as copy-paste manifests. Replace the names, IDs,
paths, hashes, dump values and core strategy with your project's.
